# Mritunjai Portfolio

A modern, responsive personal portfolio website built to showcase **Mritunjai's skills, projects, experience, and professional profile**.

🌐 **Live Website:** `https://itzsonu.github.io/mritunjai-portfolio/`

---

## ✨ Overview

This portfolio is designed as a professional online presence and includes information about:

* 👨‍💻 About / Profile
* 🛠️ Technical Skills
* 💼 Experience
* 🚀 Projects
* 🎓 Education
* 📄 Resume
* 📬 Contact Information

The website is built with a focus on **responsive design, clean UI, fast loading, and easy navigation**.

## 💻 Run Locally

Clone repository:

```bash
git clone https://github.com/itzsonu/mritunjai-portfolio.git
```

Navigate to the project:

```bash
cd mritunjai-portfolio
```

Since this is a static website, no package installation or build process is required.

You can open:

```text
dist/index.html
```

directly in a browser.

For a better local development experience, you can also use a local server such as VS Code Live Server.

---

## 🌐 Deployment

This project can be deployed for free using **GitHub Pages**.

The GitHub Actions workflow publishes the contents of the `dist/` directory.

Every push to the `main` branch can automatically trigger a new deployment.

### Deployment URL

```text
https://itzsonu.github.io/mritunjai-portfolio/
```

---

## 🔄 Updating the Portfolio

After making changes:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```

GitHub Actions will automatically deploy the latest version.
